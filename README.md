# Vocabitan

Vocabitan is a powerful popup dictionary extension for language learning, allowing users to quickly look up and learn vocabulary while browsing the web.

## Description
Vocabitan provides seamless, in-browser dictionary lookups by simply hovering over or selecting text. Designed for language learners, it enables quick definitions, reading assistance, and integration with flashcard software to streamline your language acquisition journey.

## Features
- **Instant Lookups**: Get instant definitions and readings of words via a popup.
- **Customizable**: Extensive settings for adjusting the popup appearance, behavior, and search parameters.
- **Flashcard Integration**: Effortlessly create flashcards from the words you look up.
- **Offline Capable**: Works entirely locally once dictionaries are installed.
